# W1.02 · Аудит первого билда

База аудита — `main` (`30aad444`), встроенные данные WoW Forever
`1.60.1.70450`, 24 ноября 2026 года. Для нативных проверок использована
изолированная установка `.w102qa` на Android 15 и отдельные iOS-симуляторы.
Каждый основной проход начинался с пустой локальной библиотеки.

## Маршрут и результаты

| Шаг | Действие и обратная связь |
| --- | --- |
| Первый запуск | Home показывает назначение TalentForge, состояние пустой библиотеки и закреплённую кнопку New build. Help доступен по запросу и открывается повторно. |
| Новый билд и класс | New build открывает список девяти классов с локализованными именами и иконками. В компактных конфигурациях список прокручивается. Выбор класса сразу открывает редактор, Back возвращает на Home. |
| Специализация | Нажатие на вкладку меняет дерево. Название, активная вкладка и счётчик специализации дают обратную связь; общий счётчик остаётся видимым. |
| Описание | Выбор Improved Rend / «Улучшенное кровопускание» открывает инспектор. Развёрнутая панель показывает описание; выбор таланта сохраняет число потраченных очков. |
| Ограничения | Deep Wounds / «Глубокие раны» показывает требуемый ранг Improved Rend и порог очков. Show переводит к непосредственному требованию, оставляя `0 / 51`. |
| Распределение | Нажатие `+` на Improved Rend даёт ранг `1/3` и общий счётчик `1 / 51`. |
| Имя | Нажатие на заголовок черновика открывает существующий диалог. После подтверждения имя появляется в заголовке; ранг и счётчик сохраняются. Повторное переименование доступно через меню. |
| Возврат и открытие | Home показывает продолжение работы с билдом. Билд можно открыть с Home или из списка билдов. |
| Перезапуск | После остановки процесса и нового запуска тот же билд открывается с введённым именем и `1 / 51`. |

- `FirstBuildJourneyUiTest` проходит от пустого Home через выбор класса,
  предпосылку, Show, расход очка и именование до повторного открытия после
  создания нового экземпляра приложения над сохранённой библиотекой.
  Проверка выполняется для EN и RU. На базовом коде тест воспроизвёл отсутствие
  действия названия в заголовке.

## Оставшиеся задачи

Действующая библиотека сохраняет и пустые черновики. Очистка нулевого
черновика при выходе и отдельное уведомление о сохранении черновика
описаны в V1 как часть жизненного цикла. Они требуют отдельной проверки
сценариев повтора открытия и сохранности записей. W1.02 сохраняет
текущее поведение возврата из редактора.

Физические устройства не входили в этот прогон. Приоритеты и семантика
условий выделения очков остались в ведении
[документа о правилах распределения](../talent-allocation-semantics.md).
