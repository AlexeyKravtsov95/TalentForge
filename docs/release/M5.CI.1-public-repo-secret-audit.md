# M5.CI.1 — public-repository secret audit

Date: 2026-10-19. Scope: everything a visitor of the public repository can fetch.
No secret value is reproduced here; every hit was reviewed with the matched value
redacted (length + sha256 prefix only).

## What was scanned

A fresh clone of `https://github.com/AlexeyKravtsov95/TalentForge` with every public ref:

- all branches (`refs/heads/*`) and tags;
- every pull-request head (`refs/pull/*/head`, PRs 1–47) — these stay public even
  after a branch is deleted.

Result: 390 commits, 3 671 unique blobs, all content-scanned (none over the 8 MiB limit).
GitHub Releases: none. Repository Actions secrets: none.

## Rules

1. Value patterns: AWS access key IDs (`AKIA…`/`ASIA…` …), PEM `PRIVATE KEY` blocks,
   GitHub / Slack / Google / Stripe-live tokens, JWTs, S3-style credential assignments
   (`aws_secret_access_key`, `access_key_id`, …), password/token/API-key string assignments,
   `keytool -storepass/-keypass` literals.
2. File names: `*.jks`, `*.keystore`, `*.p12`, `*.pfx`, `*.pem`, `*.key`, `*.p8`,
   `*.mobileprovision`, `.env*`, `key.properties`, `keystore.properties`,
   `signing.properties`, `credentials(.json)`, SSH private keys, `google-services.json`,
   `GoogleService-Info.plist`, `agconnect-services.json`, `.npmrc`, `.netrc`, `.pypirc`.
3. Binary keystore magic numbers (JKS `FEEDFEED`, JCEKS `CECECECE`).
4. High-entropy tokens (≥ 20 chars, mixed case + digits, Shannon entropy ≥ 4 bits/char)
   on lines that mention key / secret / token / credential / password / private.

## Recommendation for the owner (not applied)

GitHub reports secret scanning, push protection and Dependabot security updates as
**disabled**. For a public repository they are free. Enabling them is a repository security
setting and is left to the owner (Settings → Code security).
