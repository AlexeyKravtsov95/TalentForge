TalentForge is an independent, unofficial mobile talent build planner for World of Warcraft: Forever. It is a planning tool, not a game client: it does not connect to game realms or control a character.

Edit talent builds
• Plan for nine classes, each with three talent trees, using the data versions included in the app.
• Tap a talent to select it. Spend and refund points with visible buttons, or fill a talent with Max.
• Read current and next-rank descriptions and inspect requirements. Show selects one prerequisite without spending points.
• Undo, redo or reset changes. Drag to pan and pinch to zoom, with inspectors that adapt to the available screen space.

Keep your own library
• Builds are saved automatically on your device. Continue editing, rename, duplicate or delete them.
• Search by build name or class, filter by class or favorites, and sort by last edited, name or class. Group builds by class.

Import and export
• Export a build as a text code with the iOS share sheet or copy it.
• Preview an imported code before saving it as a separate build. Existing builds are preserved.

Works offline
• Bundled talent data and saved builds are available without a connection.
• Updates download only game data (JSON talent trees and texts, PNG icons) over HTTPS. The app checks the developer's signature and file hashes before using the data; it never downloads code.
• Without a connection, continue with bundled and previously downloaded data. A data version not already on the device needs a connection to download.

English and Russian
• Interface and available talent texts follow the device language. Missing Russian talent text falls back to English.

No account, ads, analytics or tracking. Your builds stay on your device and are never uploaded.
