## 4. Description

```text
TalentForge — неофициальный планировщик билдов талантов для World of Warcraft: Forever. Выберите класс, распределите очки по деревьям талантов и храните все билды на iPhone или iPad.

Планируйте
• Все девять классов, у каждого три дерева талантов.
• Нажатие выбирает талант. Очки добавляются и снимаются понятными кнопками, без скрытых жестов. Талант можно прокачать до максимума одним действием.
• Для каждого таланта видно описание текущего и следующего ранга, его требования и сколько очков нужно для его ряда.
• Можно перейти к таланту, который открывает выбранный.
• Отмена, повтор и сброс талантов.
• Дерево перемещается перетаскиванием и масштабируется щипком. Работает в портретной и альбомной ориентации, на iPhone и iPad.

Храните
• Билды сохраняются на устройстве автоматически.
• Продолжайте с того места, где остановились, прямо с главного экрана.
• Переименовывайте, копируйте и удаляйте билды.

Делитесь
• Отправьте билд коротким текстовым кодом через любое приложение или скопируйте код.
• Импортируйте код и посмотрите билд до сохранения. Импортированный билд никогда не перезаписывает другие ваши билды.

Приватно
• Без учётной записи, рекламы, аналитики и отслеживания.
• Ваши билды остаются на вашем устройстве.
• Эта версия полностью работает без интернета: данные талантов встроены в приложение.

Языки
• Интерфейс и тексты талантов на русском и английском — по языку устройства.

TalentForge — независимый неофициальный проект. Он не связан с Blizzard Entertainment, не одобрен и не спонсируется ею. World of Warcraft является товарным знаком или зарегистрированным товарным знаком Blizzard Entertainment, Inc. в США и/или других странах.
```

1661 символов. Каждое утверждение сверено со сборкой M5.IOS.1 (smoke на симуляторах, [readiness §4](readiness.md#4-устройства-и-smoke)): девять классов, три дерева, кнопки +/−/Max, «Показать», отмена/повтор/сброс, жесты, портрет и ландшафт, автосохранение, переименование/копирование/удаление, код и импорт с предпросмотром, RU/EN. Не упоминаются функции, которых нет (облако, аккаунт, экипировка, цены).

## 7. App Review Notes

```text
TalentForge — планировщик билдов талантов для World of Warcraft: Forever. Это независимый неофициальный инструмент: ему не нужны игра, учётная запись Blizzard или любая другая учётная запись; в нём нет входа, встроенных покупок, рекламы и отслеживания.

Как проверить:
1. Нажмите «Новый билд», выберите класс (например, «Маг»).
2. Нажмите на талант, чтобы выбрать его; кнопки «+» / «−» / «Max» в панели добавляют и снимают очки. Перетаскивание перемещает дерево, щипок масштабирует. Для закрытого таланта показано требование; «Показать» переходит к нужному таланту.
3. Меню ⋯ — переименование и отправка билда. «Поделиться» открывает системное меню iOS с текстовым кодом; «Копировать код» копирует его.
4. На главном экране «Импортировать билд» → «Вставить» → «Продолжить» показывает билд из кода, «Импортировать» сохраняет его как новый.
5. Кнопка ⓘ открывает «О приложении»: версия, версия данных талантов, сведения о конфиденциальности и лицензии открытого ПО.

Эта сборка не выполняет сетевых запросов: все данные талантов встроены. Язык интерфейса — по языку устройства (английский или русский).
```

1100 символов. Демо-аккаунт не нужен (входа нет): в App Store Connect оставить «Sign-in required» выключенным.

## 8. Замены для сборки OTA ON (только после M5.IOS.2)

В Description заменить строку

```text
• Эта версия полностью работает без интернета: данные талантов встроены в приложение.
```

на

```text
• Данные талантов встроены в приложение. Когда выходит обновление данных талантов, приложение загружает его по HTTPS и проверяет подпись; без сети оно продолжает работать с имеющимися данными.
```

а в App Review Notes заменить последний абзац («Эта сборка не выполняет сетевых запросов…») на (M5.IOS.2, сверено со сборкой OTA ON):

```text
Обновления данных талантов (App Review Guideline 2.5.2): после запуска, при возврате в приложение, по кнопке «О приложении» → «Проверить обновления» и когда сохранённому билду нужна версия игровых данных, которой нет на устройстве, приложение загружает по HTTPS (только GET) с https://ota.mythweld.com подписанный общедоступный каталог и файлы данных талантов. Перед использованием оно проверяет подпись каталога ECDSA P-256 ключами, встроенными в приложение, и SHA-256 каждого файла. Файлы — только данные и изображения: деревья и тексты талантов (JSON) и иконки талантов (PNG), никогда не исполняемый код; поведение и функции приложения не меняются. Запросы не содержат идентификаторов учётной записи, устройства или рекламы и содержимого билдов. Без сети приложение работает со встроенными данными. Язык интерфейса — по языку устройства (английский или русский).
```

Длина Review Notes с этим абзацем ≈ 1 750 символов (лимит App Store Connect — 4 000).
