## Historical checkout compatibility

Run [44312891719](https://github.com/AlexeyKravtsov95/TalentForge/actions/runs/44312891719)
failed because the current orchestrator passed `--reuse-from` to `origin/main`'s older CLI.

actual disposable checkout before constructing pipeline steps. Both must advertise the
option to enable reuse. Old tooling performs full build-pinned downloads and every existing
integrity/pipeline/regression check. Failed CLI inspection blocks preparation as `tooling`;
a failed pipeline is never retried with reduced checks. Capability logs accompany the report.

Regression tests exercise actual subprocess CLIs with old, partial and current capabilities,
plus a broken CLI. The historical Actions workflow executes the complete 70374 → 70450
scenario: live source acquisition, preparation, nine-class comparisons, staging, Kotlin HTTPS
client scenarios and production read-only guards, without skip/xfail options. Final run links
and exact HEAD results are recorded in PR #155 after completion.

## Independent policy fixtures and fail-closed boundaries

`tests/ota_patch_fixtures.py` generates tiny synthetic snapshots of nine classes, two nodes
with a prerequisite/point requirement, English/Russian sidecars and two committed test BLPs.
It never reads canonical production datasets or the 70959 candidate. Tests create real Git
repositories and data-only commits, build manifests, verify every gate and authorize the
immutable request tag without per-release input. Real mixed code/data, policy/config and
graph commits fail `DATA_ONLY_SOURCE`. The standing policy uses exactly
`candidate_path_allowed`; it does not authorize code, configuration or generated graph files.

Additional tests cover structural identity/rank/flag/prerequisite changes, missing PNGs,
registry/PNG SHA-256 mismatch, damaged signed-base data and warning growth. Signature, expiry,
TLS and active-file verification remain mandatory. Store delivery checks active data; the
independent archive monitor checks retained history. TLS EOF remains a transport error.
