## 4. Перенос на сайт (выполняет только владелец)

1. Закройте OA-1…OA-6 и получите юридическую проверку (OA-8).
2. В обоих файлах замените каждый `<mark class="owner-todo">…</mark>` обычным текстом. Смысл RU и EN должен совпадать.
3. Перенесите изменения в исходники сайта: проще всего применить к ним `git diff --no-index baseline/… …` (см. §1). Если исходники с 19 октября менялись, сначала сравните их с `baseline/`.
4. Удалите служебные элементы черновика: строку-комментарий `DRAFT` и `<meta name="robots" content="noindex">`, блок `<style>…</style>` в `<head>` и абзац `<p class="draft-banner">…</p>`.
5. Проверьте, что в файлах не осталось `owner-todo`, `draft-banner`, `noindex` и `⟨`:

   ```bash
   grep -nE 'owner-todo|draft-banner|noindex|⟨' privacy.html privacy-en.html
   ```

   Команда не должна ничего вывести.
6. Опубликуйте `privacy.html` и `privacy-en.html` на `legal.mythweld.com` до загрузки OTA ON сборки в магазины ([android-production-enablement §3](../../ota/android-production-enablement.md)). Затем откройте обе страницы с телефона и по ссылке из About.
