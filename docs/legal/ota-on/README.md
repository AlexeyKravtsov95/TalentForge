## 4. Перенос на сайт (выполняет только владелец)

1. Подставьте дату фактической публикации в формате опубликованной редакции («19 октября 2026 года» / «19 October 2026»)
   и сохраните копии для сайта в отдельный каталог. Пример для 25 октября 2026 года:

   ```bash
   mkdir -p legal-publish
   sed 's/{{PUBLICATION_DATE}}/25 октября 2026 года/' docs/legal/ota-on/privacy.html > legal-publish/privacy.html
   sed 's/{{PUBLICATION_DATE}}/25 October 2026/' docs/legal/ota-on/privacy-en.html > legal-publish/privacy-en.html
   ```

2. Проверьте, что в копиях не осталось служебных меток:

   ```bash
   grep -nE '\{\{|owner-todo|draft-banner|noindex|⟨' legal-publish/privacy.html legal-publish/privacy-en.html
   ```

   Команда не должна ничего вывести.
3. Перенесите копии в исходники сайта. Если исходники с 19 октября менялись, сначала сравните их с `baseline/`.
4. Решение о юридической проверке текста перед публикацией (LR-5, OA-5, OA-8) принимает владелец.
5. Опубликуйте `privacy.html` и `privacy-en.html` на `legal.mythweld.com` до загрузки OTA ON сборки в магазины
   ([android-production-enablement §3](../../ota/android-production-enablement.md)). Затем откройте обе страницы
   с телефона и по ссылке из About.
