О политике

Эта политика описывает обработку данных при использовании Android-приложения TalentForge и информационного сайта TalentForge Legal. Ответственный за приложение и сайт: Алексей Кравцов. Контакт: alexey.kravtsov95@gmail.com.

1. Данные в приложении

TalentForge — планировщик игровых билдов. Приложение работает без учётной записи и регистрации, не показывает рекламу и не содержит встроенной аналитики.

На устройстве сохраняются созданные вами билды: класс персонажа, распределение талантов, версия игровых данных, заданное вами название (если есть), а также даты создания, изменения и последнего открытия. Эти сведения находятся в закрытом хранилище приложения на вашем устройстве. Приложение не отправляет билды, их названия и распределения талантов ни на сервер обновлений, ни разработчику.

2. Обновления данных талантов

Этот раздел относится к версиям приложения, которые загружают обновления данных талантов: в них на экране «О приложении» есть кнопка «Проверить обновления». Версии без этой кнопки не запрашивают разрешение на доступ к интернету и не выполняют сетевых запросов.

Чтобы данные талантов оставались актуальными, приложение по защищённому соединению HTTPS загружает с сервера ota.mythweld.com общедоступный список обновлений и файлы игровых данных. Для этого приложение использует стандартное разрешение Android на доступ к сети. Оно не запрашивает доступ к местоположению, контактам, камере, микрофону, файлам или уведомлениям.

Приложение обращается к серверу:

  • после запуска;
  • время от времени при возвращении в приложение;
  • после нажатия «Проверить обновления»;
  • при открытии сохранённого или импортированного билда, данных для версии игры которого ещё нет на устройстве.

Автоматические проверки обновлений выполняет само приложение. Отдельного переключателя для их отключения в приложении сейчас нет. Вы можете запретить приложению доступ к сети средствами системы или устройства.

Набор запрашиваемых файлов может различаться у разных пользователей. Например, при открытии билда для другой версии игры приложение загружает файлы именно этой версии. По запрошенным адресам можно понять, данные какой версии игры понадобились приложению. Сами билды, их названия и распределения талантов при этом не передаются.

При каждом запросе сервер и сеть доставки контента (CDN) хостинг-провайдера ⟨наименование провайдера и оператора CDN — OA-3⟩ технически получают IP-адрес вашего устройства, время запроса, запрошенный адрес (URL) и заголовок User-Agent с названием и версией приложения, а также технические параметры защищённого соединения. ⟨Ведутся ли журналы запросов, сколько они хранятся, кто имеет к ним доступ и используются ли IP-адреса для чего-либо, кроме доставки файлов, — OA-1, OA-2, OA-3, OA-4⟩

Приложение не передаёт на сервер обновлений рекламные идентификаторы, идентификаторы устройства или учётной записи, cookies, содержимое билдов или буфера обмена.

Загруженные данные проверяются на устройстве по криптографической подписи разработчика и сохраняются в закрытом хранилище приложения. Если проверка не пройдена, загруженные данные не используются, и приложение продолжает работать с прежними данными. Без подключения к интернету приложение продолжает работать с уже доступными на устройстве данными.

3. Копирование, импорт и отправка

При нажатии «Копировать код» приложение помещает код билда в буфер обмена. При нажатии «Вставить» на экране импорта приложение считывает текст из буфера обмена для локальной обработки.

При выборе «Поделиться» код билда передаётся в системное меню отправки Android. Вы самостоятельно выбираете приложение-получателя. Дальнейшая обработка определяется условиями и политикой выбранного сервиса. Код билда не содержит введённого вами названия билда.

4. Резервные копии и хранение

В Android-версии отключено стандартное резервное копирование данных приложения. Загруженные обновления данных талантов хранятся в разделе закрытого хранилища, который не включается в резервные копии. Некоторые инструменты переноса данных производителей устройств могут работать иначе и не контролируются TalentForge.

Данные билдов сохраняются локально до их удаления вами. Вы можете удалить отдельные билды внутри приложения либо удалить все данные приложения, включая загруженные обновления данных талантов, через настройки Android или удаление приложения. Разработчик не располагает удалёнными копиями ваших билдов и не может удалить данные непосредственно с вашего устройства.

5. Сайт TalentForge Legal

При открытии этого сайта браузер соединяется с инфраструктурой хостинга VK Cloud. Для технической доставки страниц провайдер может обрабатывать данные соединения, включая IP-адрес и технические сведения о запросе, в соответствии со своими правилами.

Сайт не использует рекламные трекеры и инструменты веб-аналитики. Для запоминания выбранного языка он сохраняет настройку talentforge-language в локальном хранилище браузера (localStorage); вы можете удалить её средствами браузера. При первом посещении язык определяется по настройкам браузера.

6. Магазины приложений и внешние сервисы

Google Play, RuStore, AppGallery и другие площадки могут самостоятельно обрабатывать сведения об установках и взаимодействиях с магазином согласно своим политикам. Эти процессы не являются передачей данных из самого приложения TalentForge. Если вы отправляете нам письмо, предоставленные вами адрес электронной почты и содержание обращения используются для ответа на запрос.

7. Дети

Приложение не предназначено специально для детей. В приложении нет учётных записей, и оно не запрашивает у пользователей сведения о возрасте или личности.

8. Изменения и контакты

Мы можем обновлять эту политику при изменении возможностей приложения или используемых сервисов. Новая редакция будет опубликована на этой странице с новой датой обновления.
