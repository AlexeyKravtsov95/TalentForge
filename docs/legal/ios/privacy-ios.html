О политике

Эта политика описывает обработку данных при использовании приложения TalentForge для iPhone и iPad (iOS и iPadOS) и информационного сайта TalentForge Legal. Для Android-приложения действует отдельная политика. Ответственный за приложение и сайт: Алексей Кравцов. Контакт: alexey.kravtsov95@gmail.com.

1. Данные в приложении

TalentForge — планировщик игровых билдов. Приложение работает без учётной записи и регистрации, не показывает рекламу и не содержит встроенной аналитики и средств отслеживания.

На устройстве сохраняются созданные вами билды: класс персонажа, распределение талантов, версия игровых данных, заданное вами название (если есть), а также даты создания, изменения и последнего открытия. Эти сведения находятся в закрытом хранилище приложения на вашем устройстве. Приложение не отправляет билды, их названия и распределения талантов ни на сервер обновлений, ни разработчику.

2. Обновления данных талантов

Этот раздел относится к версиям приложения, которые загружают обновления данных талантов: в них на экране «О приложении» есть кнопка «Проверить обновления». Версии без этой кнопки не выполняют сетевых запросов.

Чтобы данные талантов оставались актуальными, приложение по защищённому соединению HTTPS загружает с сервера ota.mythweld.com общедоступный список обновлений и файлы игровых данных. Приложение не запрашивает доступ к местоположению, контактам, фото, камере, микрофону, файлам или уведомлениям.

Приложение обращается к серверу:

  • после запуска;
  • время от времени при возвращении в приложение;
  • после нажатия «Проверить обновления»;
  • при открытии сохранённого или импортированного билда, данных для версии игры которого ещё нет на устройстве.

Автоматические проверки обновлений выполняет само приложение. Отдельного переключателя для их отключения в приложении сейчас нет. Вы можете отключить приложению сотовые данные в настройках iOS или отключить устройство от сети.

Набор запрашиваемых файлов может различаться у разных пользователей. Например, при открытии билда для другой версии игры приложение загружает файлы именно этой версии. Запрашиваемые файлы могут указывать на версию игровых данных, которая нужна приложению. Сами билды, их названия и распределения талантов при этом не передаются.

При каждом HTTPS-запросе инфраструктура доставки (сервер и сеть доставки контента, CDN) технически получает IP-адрес вашего устройства, время запроса, запрошенный адрес (URL) и заголовок User-Agent с названием и версией приложения, а также технические параметры защищённого соединения. Провайдер этой инфраструктуры может обрабатывать технические сведения о запросах, чтобы предоставлять сервис и обеспечивать его безопасность, в соответствии со своими правилами.

Эти технические сведения могут сохраняться в журналах запросов инфраструктуры доставки и после того, как запрос обслужен. Конкретный срок хранения в этой политике не указывается, поскольку он определяется инфраструктурой доставки. Разработчик не использует журналы запросов для установления вашей личности, аналитики, рекламы или отслеживания и не объединяет их с другими данными; если у разработчика есть доступ к таким журналам, он использует их только для доставки обновлений, поддержания работы и безопасности сервиса. В сведениях о конфиденциальности приложения в App Store эти журналы указаны в категории «Диагностика» (Other Diagnostic Data) как данные, связанные с пользователем, поскольку IP-адрес может относиться к персональным данным; для отслеживания они не используются.

Приложение не передаёт на сервер обновлений рекламные идентификаторы, идентификаторы устройства или учётной записи, cookies, содержимое билдов или буфера обмена.

Загруженные данные проверяются на устройстве по криптографической подписи разработчика и сохраняются в закрытом хранилище приложения. Если проверка не пройдена, загруженные данные не используются, и приложение продолжает работать с прежними данными. Без подключения к интернету приложение продолжает работать с уже доступными на устройстве данными.

3. Копирование, импорт и отправка

При нажатии «Копировать код» приложение помещает код билда в буфер обмена. При нажатии «Вставить» на экране импорта приложение считывает текст из буфера обмена для локальной обработки; iOS может попросить разрешить вставку.

При выборе «Поделиться» код билда передаётся в системное меню «Поделиться» iOS. Вы самостоятельно выбираете приложение-получателя. Дальнейшая обработка определяется условиями и политикой выбранного сервиса. Код билда не содержит введённого вами названия билда.

4. Резервные копии и хранение

Если на устройстве включено резервное копирование (резервная копия iCloud или копия на компьютере), копия может включать данные приложения, в том числе ваши билды. Её хранит сервис резервного копирования по своим правилам; у разработчика нет к ней доступа. Загруженные обновления данных талантов хранятся в разделе хранилища приложения, который не включается в резервные копии.

Данные билдов сохраняются локально до их удаления вами. Вы можете удалить отдельные билды внутри приложения либо удалить само приложение — тогда все его данные на устройстве, включая загруженные обновления данных талантов, будут удалены. Разработчик не располагает удалёнными копиями ваших билдов и не может удалить данные непосредственно с вашего устройства.

5. Сайт TalentForge Legal

При открытии этого сайта браузер соединяется с инфраструктурой хостинга VK Cloud. Для технической доставки страниц провайдер может обрабатывать данные соединения, включая IP-адрес и технические сведения о запросе, в соответствии со своими правилами.

Сайт не использует рекламные трекеры и инструменты веб-аналитики. Для запоминания выбранного языка он сохраняет настройку talentforge-language в локальном хранилище браузера (localStorage); вы можете удалить её средствами браузера. При первом посещении язык определяется по настройкам браузера.

6. App Store и внешние сервисы

Apple может самостоятельно обрабатывать сведения о загрузках, покупках и взаимодействиях с App Store согласно своим политикам. Эти процессы не являются передачей данных из самого приложения TalentForge. Если вы отправляете нам письмо, предоставленные вами адрес электронной почты и содержание обращения используются для ответа на запрос.

7. Дети

Приложение не предназначено специально для детей. В приложении нет учётных записей, и оно не запрашивает у пользователей сведения о возрасте или личности.

8. Изменения и контакты

Мы можем обновлять эту политику при изменении возможностей приложения или используемых сервисов. Новая редакция будет опубликована на этой странице с новой датой обновления.
